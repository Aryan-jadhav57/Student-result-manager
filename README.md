Student Manager App

Overview

The Student Manager App is a simple Python-based console application designed to manage student records. It allows users to add students, view their details, and check their results based on marks.

Features

Add Student: Input student name and marks, store them in a dictionary.

View Students: Display all students with their respective marks.

Check Result: Enter a student name to check if they passed (marks ≥ 40) or failed.

Exit: Close the application gracefully.

How It Works

The app runs in a continuous loop until the user chooses to exit.

Students are stored in a dictionary with their names as keys and marks as values.

Results are determined by comparing marks against the pass threshold (40).

Requirements

Python 3.x

Usage

Clone the repository.

Run the script using:

python student_manager.py

Follow the on-screen menu to manage student records.
