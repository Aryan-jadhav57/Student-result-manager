# 🎓 Student Manager App

A beginner‑friendly **Python console application** to manage student records. This project demonstrates the use of loops, conditionals, and dictionaries in Python while providing a practical mini‑system for handling student data.

---

## ✨ Features
- **Add Student**: Input student name and marks, store them in a dictionary.  
- **View Students**: Display all students with their respective marks.  
- **Check Result**: Enter a student name to check if they passed (marks ≥ 40) or failed.  
- **Exit**: Close the application gracefully.  

---

## ⚙️ How It Works
1. Runs in a continuous loop until the user chooses to exit.  
2. Students are stored in a dictionary with names as keys and marks as values.  
3. Results are determined by comparing marks against the pass threshold (40).  

---
